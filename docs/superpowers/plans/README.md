is subordinate to the canonical specification, the task ledger, and its
work-package issue; those govern on conflict.

The September 2026 plans are historical. Their pull requests have merged, and
they describe `main` as it was when written. They stay at these paths because
accepted ADRs (ADR-0017, ADR-0024, ADR-0025) and the handoff ledger link to
them. Read them for design rationale, not for current state or open work.
